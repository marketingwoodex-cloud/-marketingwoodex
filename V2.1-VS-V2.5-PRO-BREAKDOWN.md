## 2. Deep Technical Breakdown: Woodex Admin v2.1

### A. Authentication & Sign-In Architecture
- **Responsive Frosted Card**: Centered modern dark card matching Image 3 & Image 4 UI specs with golden brand badge, styled email/password inputs with toggle visibility, and unified Google SSO sign-in.
- **Demo & Legacy Clean-up**: Eliminated all unauthenticated demo pills (`Master`, `Manager`, `Developer`, `Sales`, `Support`) and legacy GitHub SSO triggers for enterprise cleanliness.
- **Session Token Security**: Uses cryptographically secure random session tokens verified with `hash_equals()` in PHP backend to prevent timing attacks.

### B. CRM Pipeline & Automation
- **Pipeline Kanban**: Multi-line filtering (All, Interior, Furniture, Project), 4 top KPI cards (Total Pipeline, Active Leads, Conversion Rate, Projected Revenue), and drag-and-drop lead stage progression.
- **Automation Group**: Consolidated sidebar grouping under `AUTOMATION` containing AI Chatbot, WhatsApp Hub, Telegram Bot, Approvals, and Workflow Triggers.
- **Client Milestone Engine**: 4-step workflow header with bilingual English/Urdu client update templates, stage photo attachments, and automated review request links.

### C. Financial & Quotation Suite
- **8 Preloaded Starter Templates**: 1-click import for Renovation, Civil Work, Interior Designing, Interior, Fit-out, Architecture, 3D Visualization, Furniture, and Design Consultancy.
- **Dual-Bank Routing**: Support for Bank Alfalah and Meezan Bank accounts with dynamic IBAN, Swift code, and branch display on PDF exports.
- **Invoicing & Advance Payments**: Instant generation of luxury branded invoices from approved quotes, milestone schedule tracking, and advance payment ledger recording.

### D. Real-Time Bot & Integration Framework
- **Telegram Bot Integration**: Fully wired with `@WoodexInteriorBot` (`token: 8946347004:AAFqpMe7fZ7EVuLDMKQ_J4_jcCUuqrbPn7A`), supporting staff notification broadcast on new lead capture and quote approvals.
- **Unified Settings**: Consolidated `Connections & MCP` under `#/settings` -> `Connections` tab for clean single-pane configuration.

## 4. Hostinger cPanel Deployment Verification

1. Extract `Woodex Live P29-v2.1.zip` directly into `public_html/`.
2. Confirm `.htaccess` is present in root and protected subdirectories (`_private/`, `_database/`, `_templates/`, `assets/uploads/`).
3. Set folder permissions: `755` for directories, `644` for standard files, `600` for `_private/admin-db.json`.
4. Open `https://yourdomain.com/admin/` to access the Admin v2.1 suite.
