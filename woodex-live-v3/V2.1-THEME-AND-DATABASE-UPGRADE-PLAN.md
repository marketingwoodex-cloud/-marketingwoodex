## 🗄️ 1. What Happens If the Database Changes? (Deep Explanation)

### A. The Core Principle: Zero-Breaking-Change Data Contract
When upgrading from v2 to v2.1 or v3, **no table schemas, column names, or field keys are deleted or renamed**. 

```
                               ┌─────────────────────────────────┐
                               │       Universal Admin API       │
                               │        (/api/admin.php)         │
                               └────────────────┬────────────────┘
                                                │
                       ┌────────────────────────┴────────────────────────┐
                       ▼                                                 ▼
        ┌─────────────────────────────┐                   ┌─────────────────────────────┐
        │  Hostinger Shared Hosting   │                   │    Local Preview / Node     │
        │      MySQL 8.0 (PDO)        │                   │     JSON Store (Fallback)   │
        ├─────────────────────────────┤                   ├─────────────────────────────┤
        │ • InnoDB Engine             │                   │ • Flat-file portable db     │
        │ • Foreign Keys & Indexes    │                   │ • Zero server configuration │
        │ • Daily cPanel Backups      │                   │ • Instant dev environment   │
        │ • 512MB RAM optimization    │                   │ • Auto-seeds test users     │
        └─────────────────────────────┘                   └─────────────────────────────┘
```

### B. Comparison: Local JSON Store vs. Hostinger cPanel MySQL 8.0

| Feature | Local JSON Store (`admin-db.json`) | Hostinger MySQL 8.0 (`api/admin.php`) | Impact of Migration |
|---|---|---|---|
| **Storage Mechanism** | Single JSON file on disk | Relational tables in MySQL database | Zero code change in UI; API abstracts both. |
| **Concurrency** | Single-process atomic file rewrite | Multi-user row-level locking (ACID) | High traffic safe; prevents race conditions. |
| **Search & Indexing** | Array filter in memory | B-Tree indexes on `email`, `status`, `created_at` | Sub-millisecond queries even with 100k+ leads. |
| **Data Integrity** | Schema-free JSON objects | Strict types, non-null constraints, defaults | Prevents corrupted or malformed payloads. |
| **Backups** | Copy `_private/admin-db.json` | 1-click SQL dump via `#/backups` or phpMyAdmin | Full disaster recovery with point-in-time restore. |

### C. What if You Change a Model or Table?
- **Adding new optional fields** (e.g. `whatsapp_verified`, `boq_notes`): **100% Safe**. Defaults to `null` or empty without affecting old records.
- **Renaming or removing fields**: **Dangerous (Avoided)**. We never rename existing columns to guarantee 100% backward-compatibility with v2.

## 🚀 3. Upgraded Feature Specifications

### 1. Hierarchical File Manager (`#/files`)
- **Directory Tree**: Browse `/assets/`, `/assets/img/`, `/assets/img/projects/`, and `/assets/fonts/`.
- **Breadcrumbs**: Clickable folder path navigation.
- **Copy URL**: 1-click copy relative asset path (`/assets/img/projects/lake-city-hero.webp`) directly to clipboard for CMS insertion.

### 2. 360° Site Health Diagnostics (`#/health`)
- **Environment Checklist**:
  - `PHP 8.2+` (Optimized for Hostinger Shared Plan)
  - `512MB RAM Limit` (Hostinger Business/Premium Tier)
  - `GD & WebP Extension` (Automatic image compression)
  - `OPcache Active` (Zero PHP compilation overhead)
  - `HSTS & SSL Encryption` (A+ Security Grade)
- **External API Pings**:
  - Google Workspace SSO ping
  - Meta WhatsApp Cloud API ping
  - Telegram Gateway ping

### 3. Integrated Third-Party Diagnostic Hub (`#/settings`)
- Dedicated sub-tabs:
  - **Google Workspace SSO & Sheets**: Client ID, Client Secret, Google Sheet ID, and test sync button.
  - **Meta & WhatsApp Cloud API**: Access Token, Business ID, Phone Number ID, and webhook validation.
  - **Telegram Alert Bot**: Bot Token, Chat ID, and 1-click test alert dispatcher.
  - **SMTP Mailer**: Host, Port, TLS encryption toggle, and test email sender.
