## 🧱 3. Preline Blocks Architecture Across All 52 Screens

| Block Category (Preline.co) | Admin Modules Using This Block Pattern | UI Pattern & Implementation |
|---|---|---|
| **KPI & Ranking Cards** | `#/dashboard`, `#/speed`, `#/wainsights`, `#/aireport` | 4-column metric cards with neon sparklines and % delta trend pills. |

| **Forms & Line-Item Builders** | `#/quotes`, `#/business`, `#/profile` | Interactive BOQ quotation builder, tax calculations, PDF generator. |
| **Communication & Chat** | `#/chat`, `#cx-dock`, `#/wahub`, `#/telegram` | 4-pane shared inbox + collapsible floating dock with auto-open on alert. |
| **Marketing & CMS Grids** | `#/blog`, `#/portfolio`, `#/services`, `#/heroes`, `#/library` | 3-column card grid CMS with tag badges, image uploaders & drawer editors. |
| **Search & Command Palettes** | Top Search Bar (`Ctrl+K` modal) | Full-text global search across all 147 pages, leads, quotes, and screens. |
| **System & Health Checks** | `#/health`, `#/database`, `#/files`, `#/settings` | 360° diagnostics checklist (PHP 8.2, 512MB RAM, GD/WebP, OPcache, SSL). |

## 💬 4. Floating Live Chat Widget & Contrast Standard

1. **Floating Trigger Dock (`#cx-bub`)**:
   - Fixed pill at bottom-right with cyan glow and pulsating unread dot (`💬 Live chat`).
   - Click to expand/collapse.
   - **Auto-Open on Inbound Message**: Automatically opens when a new visitor message or alert is received.
2. **High-Contrast Bubble Color Tokens**:
   - **AI Assistant**: `#f0fdfa` text on `#0b2230` dark blue background with `#00b8db` left accent and `#38bdf8` timestamp.
   - **Visitor / Lead**: `#f8fafc` text on `#1e293b` charcoal slate with `#94a3b8` timestamp.
   - **Staff / Agent**: `#04222b` text on `#00b8db` solid cyan with `#083344` timestamp.

## 🗄️ 5. Database Architecture: Dual-Driver Zero-Breaking-Change

- **Hostinger Shared Plan (Production)**: Uses MySQL 8.0 InnoDB with connection pooling, indexes on `email`/`stage`/`created_at`, foreign keys, and automated cPanel backups.
- **Local Sandbox (Preview)**: Uses flat-file `_private/admin-db.json` with zero server configuration for instant development speed.
- **Zero Breaking Changes**: All table columns and API schemas remain 100% identical between v2, v2.1, and v3.
