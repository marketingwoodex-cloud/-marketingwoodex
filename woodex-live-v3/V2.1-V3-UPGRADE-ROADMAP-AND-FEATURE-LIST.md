## 🎯 1. Bug Fix: Auth Card Overlay on Dashboard (Resolved)

### Cause & Solution:
- **Issue**: When signed in, the dashboard loaded in the background while `#auth` remained visible over `#app`.
- **Root Cause**: `.auth { display: flex !important; }` in CSS was overriding the HTML `[hidden]` attribute.
- **Fix Applied**: Added explicit high-priority hiding rules:
  ```css
  #auth[hidden], .auth[hidden], #app[hidden], .app[hidden], [hidden] {
    display: none !important;
  }
  ```
- **Result**: Signing in cleanly hides `#auth` and reveals `#app` instantly with zero overlay glitches.

## 🎨 3. UI Block Refinement Details

1. **Table Blocks (`.tbl-wrap` & `.tbl`)**:
   - High-contrast text on dark surfaces (`#ffffff` headers, `#e5e7eb` body text).
   - Smooth hover highlight (`rgba(255, 255, 255, 0.03)`).
   - Status badges with border glow (`.badge.ok`, `.badge.warn`, `.badge.bad`, `.badge.info`).
2. **Tab Navigation Blocks (`.tabs` & `.subnav`)**:
   - Preline Segmented Pill style (`background: #111318; border: 1px solid #20242f; border-radius: 9999px;`).
   - Active state highlighted in solid cyan (`#00b8db`) with dark label `#04222b` (WCAG AAA compliant).
3. **Sidebar Rail Collapse Mode**:
   - Click the rail button (`#rail`) at the top right of the sidebar to collapse into an icon rail (`72px` width) for maximum workspace canvas.
