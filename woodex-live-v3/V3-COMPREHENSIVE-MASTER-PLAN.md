## 🧱 2. Tailored Block Specifications by Category

### Category 1: Core Conversion & Tools (`BLK-CORE-*`)
- `BLK-HERO-LUX`: Split grid with 3D render preview, verified luxury project badge, and instant CTA buttons.
- `BLK-EST-CALC`: Interactive real-time cost estimator calculating square-footage rates in PKR.
- `BLK-BOOK-CAL`: Calendar schedule booking for on-site consultation with slot selector.
- `BLK-GALLERY-FILTER`: Filterable project masonry showcase with lightbox.

### Category 2: Residential & Villa Hubs (`BLK-RES-*`)
- `BLK-RES-SPECS`: Plot size dimensions (50x90 for 1-Kanal, 35x65 for 10-Marla), covered area, and room allocation matrix.
- `BLK-RES-BOQ`: Detailed itemized cost schedule for grey-structure finishing, false ceiling, flooring, and joinery.
- `BLK-RES-FLOORPLAN`: High-res 2D/3D architectural layout plan inspector.

### Category 3: Room Specialties (`BLK-SPEC-*`)
- `BLK-KITCHEN-MAT`: UV High-Gloss vs Acrylic vs Tactile Veneer comparison cards with thickness & warranty badges.
- `BLK-WARDROBE-SYS`: Walk-in closet modular configuration planner with LED lighting channels and glass slider options.
- `BLK-CEILING-LIGHT`: False ceiling architectural layering and lighting lumens guide.

### Category 4: Commercial & Corporate (`BLK-COMM-*`)
- `BLK-COMM-METRICS`: Employee desk density, acoustic decibel reduction ratings, HVAC integration.
- `BLK-COMM-PHASES`: Rapid fit-out timeline milestones minimizing commercial downtime.
- `BLK-COMM-LOGOS`: Corporate client proof wall and commercial project badges.

### Category 5: City Authority Hubs (`BLK-CITY-*`)
- `BLK-CITY-MAP`: Map of active project sites in DHA Lahore, Bahria Town, Gulberg, Islamabad Sector F/E, etc.
- `BLK-CITY-BYLAWS`: Local society approval compliance (LDA, DHA, CDA, Bahria) guidance.
- `BLK-CITY-CONTACT`: Local area consultant hotline and quick site survey dispatcher.

### Category 6: Insights & Editorial (`BLK-BLOG-*`)
- `BLK-BLOG-HEADER`: Clean article title, author credentials, reading time, and publish date.
- `BLK-BLOG-TOC`: Sticky auto-generated Table of Contents for seamless anchor navigation.
- `BLK-BLOG-CALLOUT`: High-contrast key takeaway callouts and embedded cost estimation cards.

## 🔒 4. Safety & Non-Regression Rules

1. **Zero Impact on Admin v2**: Admin v2 (`/admin/`) remains untouched and 100% operational as a fallback reference.
2. **Pure CSS & Zero Node Build Dependencies**: All blocks run on native browser standards for instant load times and effortless Hostinger shared-hosting compatibility.
3. **Automated Checkpoints**: Every category phase concludes with a contrast check, HTML syntax validation, and live HTTP preview verification.
