Woodex admin — demo copy

This folder (demo-preview/) is a copy of admin/ that needs no PHP: demo-api.js answers the admin's own API calls in the browser. The original admin folder is untouched.

Working with real demo data

  • Dashboard — KPIs, lead/paid series, pipeline funnel, follow-ups, overdue list
  • Expenses (Money → Expense log) — 10 vouchers, budget-versus-actual, filters, CSV
  • Document packs (Money → Document packs) — tick types, build a pack, workbook, CSV, print packet
  • Leads & pipeline, Clients, Bookings, Quotations, Invoices — Woodex-shaped records
  • Regional ops — the 12 node codes, projects, milestones, ledger, rate cards
  • Inbox, Team feed, WhatsApp, Media, SEO, Health, Theme, Telegram, Backups, Users, Activity log

Opens but has no data behind it

  • Anything that would read or write the real database — settings forms save into nothing
  • Uploads (media, logos, backups) — there is no disk here on purpose
  • The page builder's saved pages, Google/Sheets sync, Telegram and WhatsApp bridges

What is deliberately different from the live site

  • The dark bar at the top: this is the demo, and it says so on every page
  • Writes are acknowledged and thrown away; reload the browser and the demo starts over
  • No PHP runs at all — the API is JavaScript in this folder

How to see the real thing

Deploy woodex-live-p23/ to PHP 8.2 + MySQL (docs/V2.7-PRELINE-UPGRADE-PLAN.md §9 has the checklist) and open /wx-install.php once. Or locally, on a machine with PHP and MySQL: php -S 0.0.0.0:8080 index.php.
