# Woodex Admin v2.5 Pro vs. V2.1→V3 Roadmap: Breakdown of Differences

**Compared:**
- **Roadmap:** `woodex-live-v3/V2.1-V3-UPGRADE-ROADMAP-AND-FEATURE-LIST.md` (branch `arena/8a776c65-marketingwoodex`, dated Oct 8, 2026). It marks 53 feature rows as "✅ Complete in v2.1".
- **Admin:** "Woodex Admin v2.5 Pro" (`woodex-live-p23/admin/`, `admin.css`/`admin-*.js` at version `2.5.1`), running on the local preview at port 8080. The `sbx-…arena.site` link opens only inside Arena, so I could not inspect it directly. It is the same codebase.

**Method:**
1. **Route audit (live):** logged in as the owner, opened every route named in the roadmap plus the admin's own navigation, and checked each screen's rendered content.
2. **Feature check (source):** searched the admin source for each named feature. Keyword matches are only indicative, so each gap was confirmed by reading the code.

This is a static and route-level check. Individual features were not clicked through, so "present" means the screen and code exist, not that every button works.

| Measure | Result |

**Bottom line:** the roadmap is mostly accurate. Almost every module exists and renders. The gaps are concentrated in login options, two named sub-features, and role naming.

## 4. Items the Roadmap Describes That Don't Match This Codebase

- **Port 8083 and `/admin-v2.1/`:** the roadmap's deployment plan refers to these. Neither exists in this project. The `woodex-live-v3/` folder it describes lives on branch `arena/8a776c65-marketingwoodex`, not on this branch.
- **Database fallback:** the v2.1-vs-v3 breakdown says the admin falls back to `_private/admin-db.json`. The code uses `_private/db.json` only. No `admin-db.json` reference exists.

---

## 5. Recommended Next Steps

1. **Decide on GitHub SSO and demo logins.** Demo logins were removed on purpose. Adding GitHub SSO means an OAuth app and a client secret.
2. **Configure Google SSO** by saving a client ID in Integrations (owner-only). Until then the button is inactive.
3. **Build bank reconciliation** (match deposits to invoices) if Payments needs it, and **build the WhatsApp hourly heatmap** if Insights needs it.
4. **Align role names:** either rename the roles to Master/Manager/Developer or update the roadmap text.
5. **Correct the roadmap:** change the five rows above from "✅ Complete" to their real status, and remove the port 8083 and `admin-db.json` references.
