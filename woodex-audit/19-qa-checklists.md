# QA Checklists (index)

The full checklists are in `qa/`:
- `qa/smoke-test-checklist.md` — post-deploy smoke test (not run; live BLOCKED).
- `qa/regression-test-matrix.md` — maps each fix to its test and status.
- `qa/release-gate-checklist.md` — gates A–G (prompt §12) with current status.

Status for each checklist item uses PASS, FAIL, BLOCKED, NOT RUN, or NOT APPLICABLE. No item is ticked without evidence.
