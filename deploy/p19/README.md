# Woodex — Phase 19 full update

**File:** `woodex-live-p19-full.zip` (whole site + Admin v2). Your data on the server (`_private/`, database, uploads) is not touched.

## Install (5 minutes)
1. Hostinger → **File Manager** → `public_html`.
2. **Upload** `woodex-live-p19-full.zip`.
3. Right-click it → **Extract** → tick **Overwrite** → Extract.
4. Delete the zip. Open the site and press **Ctrl + F5**.
5. Sign in to `/admin/` once — new tables/columns are added automatically.

## After installing (first-time setup)
1. **Content → Forms**: type the default alert email (woodexinterior.pk@gmail.com) → **Save**. Optional: a WhatsApp number per form.
2. **Enquiries & leads → Import**: upload each monthly tab of your lead sheet (Google Sheets → File → Download → CSV). Keep "Also add to Clients" ticked.
3. **Content → FAQ groups**: open a group → tick the pages → Save.
4. **Team**: add department / photo / LinkedIn; tick Featured for partners → Pages & heading → Update website.
5. **Estimator**: Templates → "Save current as template" first, then add services or adjust rates → **Save & publish**.
6. **Page templates → Template library**: add the layouts you like, then "Apply to pages".
